# API de Veículos

Projeto desenvolvido para a disciplina de Desenvolvimento de Websites.

## Tecnologias

- Node.js
- Express
- JavaScript
- Insomnia

## Funcionalidades

A API possui um CRUD de veículos:

- POST /veiculos - Cadastrar veículo
- GET /veiculos - Listar veículos
- GET /veiculos/:id - Buscar veículo por ID
- PUT /veiculos/:id - Editar veículo
- DELETE /veiculos/:id - Excluir veículo

## Executar o projeto

Instale as dependências:

npm install

Depois execute:

node app.js

O servidor será iniciado em:

http://localhost:3000
